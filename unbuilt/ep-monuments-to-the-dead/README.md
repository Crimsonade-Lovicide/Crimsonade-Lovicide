## Files

- `SCRIPT.md`: the approved script. `RESEARCH_*.md`: fact-checks.
- `shotlist.json` / `SHOTLIST.md`: every shot with prompts and budget, generated by `build_shotlist.py`.
- `host/`: the new-wardrobe reference portraits used for every Seedance shot.
- `edit/assemble.py`: builds the voice cut. **The edit list is generated from `shotlist.json`** (shots that share a voice line split it; `(overlay on X…)` cards go over shot X), so a script change flows through without retyping an edit list. `LIST=1 python3 edit/assemble.py <assets> x` prints it; `ONLY=3,8` re-renders selected beats.
- `edit/score.py`: the episode 1 scoring (theme on its 16-beat phrase grid, sidechain duck, -14 LUFS), with beat indices read from `build/timeline.json`.
- `edit/qc_sync.py`: transcribes each Seedance shot against the script and writes a 4-frame strip for likeness/wardrobe review.
- Shared from episode 1: `../ep-magnificent-delusions/edit/tighten.py` and `sync_audio.py`.

## Rebuild

```
export FFMPEG=<ffmpeg>
python3 edit/assemble.py <assets> voice_cut.mp4
python3 edit/score.py <assets> music.mp3 voice_cut.mp4 final.mp4
```
`<assets>` holds `audio/t_<KEY>.wav` (tightened TTS), `audio/t_s_<ID>.wav` (sync voice from `sync_audio.py`), `vid/sync_<ID>.mp4`, `vid/br_<ID>.mp4` and `img/<ID>.png`.

## What happened in the render (27 Sep 2026)

- **Stills (48 + 6 retakes).** CO6 and Y3 came back with a pyramid far too small for "twice the height of St Paul's", so both were redone at true scale, with St Paul's in frame for comparison. P1v, P3 and P4b came back as a photo inside a blurred border; they were redone full-bleed. P1v then had a "BUENOS AIRES, 1952" caption, which was cropped off. Y4b's catacomb was full of robed, biblical-looking figures, so it was redone as an empty Georgian brick gallery.
- **Black bars.** Some start frames came back pillarboxed, and Kling keeps the bars. `assemble.py` detects paired pure-black edges and crops them. It checks both sides, so a single dark edge is not treated as a bar. P5a's start frame also carried a burned-in timecode; it gets a fixed 1.16× crop.
- **Seedance.**
  - **P1:** the first take ignored the audio reference and produced invented speech. A plain re-render fixed it.
  - **C7 (IP filter):** the IP filter rejected C7 three times, twice with the same voice file and once in a completely different set. It passed with a fresh TTS take of the same line, which suggests the old audio file was what tripped the filter. Rejected jobs are refunded automatically.
- **Hand-patched sync audio:**
  - **Y6:** Seedance said "By rights" for "Air rights". `sync_audio.py` couldn't match the word because whisper hears the clean take as "Ayer". The clean take's "Air ri-" was spliced over the same 0.46s span, with level and pitch matched. The larger whisper model then hears "Air rights".
  - **C7:** Seedance dropped the plural "s" of "Stuarts". The clean take's "-ts" hiss was grafted into the closure before "never". "Stuarts" and "stewards" sound alike in British English, so whisper spells it either way; the check that matters is that the hiss is back.
  - Originals are kept as `t_s_Y6_native.wav` and `t_s_C7_native.wav`.
- **Voice QC.** All 50 lines pass. Every match below 1.0 is a numeral or a spelling difference ("£70,000", "Boulet" for Boullée, "stories" for storeys).
- **Spend.** The balance was 1,099 before the render and 248.5 after, so about 850 credits including the earlier tests. The budget was 880.
